## Decisions (do not re-ask)
- No Docker needed; Docker is an optional add-on. The hub is a plain Node program (`apps/server`, Node 24, `node:sqlite`, `ws`, the `peer` signalling server). Tray icon is a library helper process that talks to the hub over localhost; the status page (localhost only) always works.
- The hub holds **sealed bytes only**. It sees device ids, entry ids (random), scope ids (random patient ids), stamps (times) and sizes. Never a key. Device tokens, not the household key, authenticate a device.
- Hub carries: sealed entries (put/get/summary/ids), and per-device sealed **state blobs** (device list and household keys, sealed with a household key). **Patient keys never go through the hub**: they travel only by pairing or by two devices meeting (M6).
- The wizard offers both network routes: Tailscale (works away from home) or home Wi-Fi only (own certificate); the user chooses.
- Push text private by default. Push events: started, past the alert time, recorded.
- Recording never waits for the hub. Turning the hub off changes nothing. No change to clinical rules; nothing added to the recording screen.

## Where things go
- `apps/server/` (new): `src/db.ts` (SQLite), `src/hub.ts` (the hub as a class, testable without HTTP), `src/http.ts` (HTTP, WebSocket, signalling), `src/status.ts` (status page), `src/main.ts` (entry), `scripts/` (start-on-boot files), tray in `apps/tray/`.
- `packages/sync/src/hub.ts` (new): the device side of hub sync (digests, push, pull, state blobs) over a `HubApi` interface; `hubClient.ts` for fetch.
- App: `apps/web/src/household/` (service uses the hub when a hub address is set), Household screen gets "Hub".
- Messages: `packages/i18n/src/messages/m7/en.ts` + `m7/<lang>.ts` + `m7/tr.ts`, wired like m6.

## Open points for the user (found while building)
- **https is required** (reasons and the two routes: `docs/decisions/m7-hub-reach-csp-keys.md`). A page served over https cannot call an http hub, and the app on Vercel is https. The hub must be reached over https (Tailscale `tailscale cert`, or an own certificate trusted on each phone), or the app must be opened from the hub itself (`HUB_APP`).
- **CSP in `vercel.json`: decided 2026-11-02 — NOT widened (most private option).** A household with a hub opens the app from the hub's address (`HUB_APP`); the Connect form says so. `vercel.json` is unchanged by M7. Reasons: `docs/decisions/m7-hub-reach-csp-keys.md`.
- Patient keys never go through the hub; a device that missed a key change gets them when it next meets another device. **Run 2 must add:** a notice for changes that cannot be opened yet; automatic reload of the hub's certificate; and **device-targeted key delivery through the hub (decided: build it, it is the option that keeps the guarantee)**. Reasons: `docs/decisions/m7-hub-reach-csp-keys.md`.
