# M0: Foundation (S–M)
**Goal:** an empty but fully wired project, and the checklist that defines "every 6.1 feature".

**Work:**
1. **Repositories:** rename the 6.x repo to `AuraTrack-v6`, tag `v6.1.0` and archive it (you confirm each GitHub step). Create the new `AuraTrack` repo (GPL-3.0) and copy this plan into `docs/plan/`, with `STATUS.md`.
2. **Monorepo:** pnpm workspaces with `apps/web` (Vite, React 19, TS strict) and the empty packages: `model`, `store`, `sync`, `ui`, `reports`, `i18n`. Shared configs: TypeScript, ESLint, Prettier, Vitest.
3. **CI** (GitHub Actions): install, type check, lint, unit tests, build, bundle-size check. The end-to-end job is added after the tool trial.
4. **End-to-end tool trial** (see the Testing strategy). Record the result and the reason in `docs/decisions/e2e-tool.md`.
5. **PWA shell:**
   - manifest and service worker in prompt mode (updates wait for a tap, never during recording)
   - strict security headers (CSP), no third-party scripts
   - the deployment target set up on a new preview address
6. **Design tokens** carried over from 6.1: colours, accent colours, dark/light, text sizes, spacing, radii, z-order. Only tokens, no components yet.
7. **The 6.1 feature inventory** in `docs/plan/feature-checklist.md`: every screen, button, setting, report section, export, reminder, background behaviour and translation. Each item gets an ID (F-001…), the 6.1 behaviour, and the milestone that rebuilds it. Made by reading the 6.1 code systematically, and **reviewed by you**.
8. **The 6.1 report inventory** in `docs/plan/report-inventory.md`: each section of the neurologist report, event log, monthly diary and EEG report, with reference output generated by 6.1 from **made-up test data** (never real data). It is the baseline for M5.

**Done when:**
- CI is green on an empty app that installs as a PWA and opens offline.
- The tool decision is recorded.
- You've approved the feature checklist.

**Handover:** STATUS.md updated; the checklist IDs are used in every later milestone.
