# M7: Household hub and push alerts (7.1) (L)
**Goal:** a household computer, Pi or NAS keeps everything synced in the background and alerts phones with the app closed.

**Work:**
1. **`apps/server`:** Node, storing sealed change-log entries in SQLite. It has device tokens issued at joining, revocation, a connection broker for internet sync, and automatic encrypted daily backups.
2. **Packaging:** a short prototype decides between an installed desktop app and a Node service with a tray icon. Plus a Docker image for a Pi or NAS, and a setup wizard (pairing QR, private-network check such as Tailscale, test connection).
3. **App side:** a hub address in Household settings; background push and pull whenever the app runs; the hub replaces the public broker when present.
4. **Push alerts:**
   - Web Push from the hub with VAPID keys
   - alerts sealed end to end and opened by the service worker
   - events: seizure started, past the alert time, recorded
   - settings per device and per patient, and private lock-screen text
   - requirements and limits stated in the app
5. **Tests:** the server's own tests, multi-device tests with the hub on and off, and push to a test endpoint.

**Done when:**
- With the hub on your computer, a seizure on one phone reaches the others and alerts them with their apps closed.
- Turning the hub off changes nothing for recording.
- 7.1 is tagged.
