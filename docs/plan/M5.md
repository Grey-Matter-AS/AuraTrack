# M5: Reports, backup and switch-over (M–L)
**Goal:** the neurologist PDF at least as good as 6.1, then better, and the move from 6.1 to v7.

**Work:**
1. **Port the 6.1 reports faithfully first,** using the M0 report inventory: neurologist report, event log, monthly diary, EEG diary, and CSV. Compared side by side with 6.1 output from the same imported data.
2. **Then the agreed additions,** shown to you section by section first:
   - the vertical seizure timeline per seizure (README section 5.1): vector, boxes alternating sides, continuing in columns, true scale as an option, with the first symptom
   - the graphical History timeline for the report period (seizures, between-seizures entries, medication changes)
   - between-seizures symptoms over time
   - body-map figures
   - ILAE type
   - recovery times
   - time-of-day and sleep/wake patterns
   - clusters and long seizures against the patient's own rule
   - medication changes and adherence against seizure frequency
   - sharper vector charts
   - a summary page first
3. **Generated in the worker;** Save as PDF as now, plus Share (share sheet), and a print preview.
4. **Backup and restore UI:** every patient or one, encrypted, restore with counts, the copy-everything option for a new phone, the recovery kit print.
5. **Switch-over rehearsal:** import the latest 6.1 backup into v7 on all your devices and compare the reports.

**Done when:**
- You've checked the 6.1-faithful report against 6.1, and approved the additions.
- Backup, restore and import are rehearsed on your devices.
- **7.0 can be used instead of 6.1** for a single device; household sync comes in M6.
