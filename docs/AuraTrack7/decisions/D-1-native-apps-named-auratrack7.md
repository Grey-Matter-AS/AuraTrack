# D-1: Native apps named AuraTrack7; the PWA paused

**Decided:** 2026-11-03, by you, in the native-apps discussion. Part of `../ROADMAP.md`.

## Decision
Native apps for iPhone, iPad, Apple Watch, Android phones and tablets, and Wear OS, all named **AuraTrack7**. The PWA is paused and later shrinks to desktop use (its new role is decided in N27).

## Why
Families asked for native apps. The PWA cannot alert with the app closed, cannot start from the lock screen reliably, and has no watch.
